# P2PSec Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A decentralized LAN privileged-access (PASM) password manager: one node per IT staff member, MITM-resistant pairing, custodian-held group credentials with checkout/check-in leases, tamper-evident audit, ServiceNow-style UI, and a seeded six-node Docker demo.

**Architecture:** Each node is one Python asyncio process. FastAPI serves a local-only REST API and the built React UI. A raw-TCP peer service speaks a framed protocol: commit-reveal + SAS for pairing, then Noise_KK for sessions. State lives in SQLite. Secrets are encrypted under two KEK-wrapped key tiers (personal and service).

**Tech Stack:** Python 3.12, FastAPI, uvicorn, cryptography, noiseprotocol 0.3.1, argon2-cffi, SQLite, pytest + pytest-asyncio; React 19 + Vite 8 (no UI kit, hand-rolled ServiceNow-like CSS); Docker multi-stage.

**Spec:** `docs/superpowers/specs/2026-10-29-p2psec-design.md`

## Global Constraints

- One fixed protocol suite, `PROTO_VERSION = 1`, no negotiation.
- Argon2id `t=3, m=65536 KiB, p=2`, 16-byte salt.
- AEAD: ChaCha20-Poly1305, random 12-byte nonce, AAD = `f"{record_type}|{record_id}"`.
- Fingerprint = first 16 bytes of SHA-256(ed25519_pub ‖ x25519_pub), shown as hex in groups of 4.
- Frame: 4-byte big-endian length, max 1 MiB.
- SAS = 6 decimal digits. Pairing timeout 120 s.
- Message replay cache 24 h, timestamp skew limit 300 s.
- Lease sweep every 15 s. Pending requests expire after 24 h. Default rotation window 30 days. Idle UI auto-lock 10 min.
- Ports: UI/API 8000 (container), peer 7600, beacon UDP 7601.
- Demo password `p2psec-demo`. `DEMO_SEED` refused unless `DEMO_MODE=1`.
- Sender identity is always the channel's pinned peer, never a body field.
- Critical-criticality credentials are never auto-approved. Critical/High rotate on check-in.
- No Claude attribution in commits.

## Review Focus

1. **A request arrives while the UI is locked.** It must queue for human approval or be auto-approved via the service key, and never crash because the personal key is missing. Test: `test_request_while_soft_locked` in Task 6.
2. **The peer is offline when an approval, revoke or receipt is sent.** The message must be queued in `outbox` and delivered on reconnect. Test: `test_outbox_redelivers` in Task 7.
3. **A lease expires while the recipient node is down.** On boot, the sweep must delete the expired lease immediately and send its receipt. Test: `test_expired_lease_swept_on_boot` in Task 6.
4. **The same requester asks twice for the same credential.** The existing lease must be extended, not duplicated. Test: `test_duplicate_request_extends` in Task 6.
5. **A wrong master password, repeated.** It must fail with a 401, log `UNLOCK_FAILED`, and leave the vault intact. Test: `test_wrong_password` in Task 2.

## File structure

```
backend/p2psec/
  config.py      Settings from env
  crypto.py      keys, fingerprint, aead, hkdf, canonical_json, sign/verify
  vault.py       KEK, two key tiers, field encryption, lock states
  db.py          SQLite schema + connection helpers
  audit.py       hash-chained signed log, verify, anchors
  framing.py     length-prefixed async stream framing
  pairing.py     commit-reveal + SAS state machine (pure, transport-agnostic)
  channel.py     Noise_KK session wrapper + message envelope (msg_id, ts, replay)
  groups.py      group documents: sign, validate chain, majority rule, forks
  engine.py      requests, policy, leases, rotation tasks, sweeper
  peer.py        TCP peer server/client, dispatch, outbox, custodian sync
  discovery.py   UDP beacon
  seed.py        P2PSec demo team, deterministic
  api.py         FastAPI routes + auth/CSRF
  node.py        Node object wiring everything; main()
backend/tests/   one test file per module + test_integration.py
frontend/        Vite React app (src/pages/*, src/components/*, src/api.js, logo.svg)
Dockerfile, docker-compose.yml, docker-compose.lan.yml, README.md
```

### Task 1: Crypto primitives + project scaffold
**Files:** `backend/requirements.txt`, `backend/pytest.ini`, `backend/p2psec/{__init__,config,crypto}.py`, `backend/tests/test_crypto.py`
**Produces:**
- `Identity` dataclass with `ed_priv` and `x_priv`, plus `ed_pub_bytes()`, `x_pub_bytes()` and `fingerprint()`.
- `Identity.generate()` and `Identity.from_seed(seed: str, node_id: str)` (HKDF-derived).
- `fingerprint(ed_pub: bytes, x_pub: bytes) -> str`
- `aead_encrypt(key, plaintext, aad) -> bytes` (nonce‖ct) and `aead_decrypt`.
- `hkdf(ikm, salt, info, length=32)`
- `canonical_json(obj) -> bytes` (sorted keys, no spaces, UTF-8).
- `sign(ed_priv, data) -> bytes` and `verify(ed_pub, sig, data) -> bool`.
- [ ] Tests:
  - aead round-trip; wrong AAD raises; tampered byte raises;
  - `from_seed` is deterministic and differs per node id;
  - fingerprint format is `xxxx xxxx …` with 8 groups;
  - verify rejects a modified message.
- [ ] Implement, run `pytest tests/test_crypto.py`, PASS.

### Task 2: Vault with two key tiers
**Files:** `vault.py`, `tests/test_vault.py`
**Consumes:** crypto.
**Produces:**
- `Vault.create(password) -> (Vault, header: dict)`, where the header holds the salt, the Argon2 params and both wrapped keys.
- `Vault.unlock(header, password)`, raising `BadPassword`.
- Properties `personal_unlocked` and `service_unlocked`.
- `soft_lock()`, which wipes the personal key, and `full_lock()`, which wipes both.
- `enc(tier: "personal"|"service", record_type, record_id, plaintext: bytes) -> bytes` and `dec(...)`, raising `Locked`.
- `rewrap(old, new)`.
- [ ] Tests:
  - round-trip in both tiers;
  - `test_wrong_password` raises `BadPassword` and the header is unchanged;
  - after `soft_lock`, personal `dec` raises `Locked` but service `dec` still works;
  - after `full_lock`, both raise;
  - after `rewrap`, the new password works and the old one fails.

### Task 3: DB + audit log
**Files:** `db.py`, `audit.py`, `tests/test_audit.py`
**Produces:**
- `open_db(path) -> sqlite3.Connection` creates these tables:
  `meta`, `contacts`, `credentials`, `group_docs`, `group_secrets`, `requests`, `leases_out`, `leases_in`, `rotation_tasks`, `audit`, `receipts`, `anchors`, `outbox`, `seen_msgs`, `events_sync`, `alerts`.
- `AuditLog(conn, identity).append(event_type, subject: dict, details: dict, ts=None) -> dict`
- `.verify() -> (ok: bool, first_bad_seq: int|None)`
- `.head() -> (seq, hash)`
- `record_anchor(peer_fpr, seq, hash) -> bool`, which returns False and inserts an alert on regression or mismatch.
- [ ] Tests:
  - an appended chain verifies;
  - editing a row's details breaks verify at that seq;
  - deleting a middle row breaks it;
  - an anchor with a lower seq triggers `LOG_ANCHOR_MISMATCH`;
  - an anchor with a different hash at the same seq triggers it.

### Task 4: Framing + pairing protocol
**Files:** `framing.py`, `pairing.py`, `tests/test_pairing.py`
**Produces:**
- `async send_frame(writer, bytes)` and `async recv_frame(reader) -> bytes`, which reject anything over 1 MiB.
- `PairingInitiator(identity, card)` and `PairingResponder(identity, card)`. Each is a pure step machine (`msg1()`, `on_msg2()`, …) that ends with `.sas: str` and `.peer_card: dict` (verified signature over the transcript hash).
- `card = {name, title, ed_pub, x_pub, demo: bool}`.
- [ ] Tests:
  - an honest run gives equal SAS and the cards are exchanged;
  - `test_mitm_substitution_mismatched_sas`: a relay that swaps in its own keys on both legs gives different SAS;
  - `test_commit_mismatch_aborts`: a revealed key that doesn't match the commit raises;
  - `test_card_signature_bad_rejected`;
  - a 1 MiB+1 frame is rejected.

### Task 5: Noise_KK channel + envelope
**Files:** `channel.py`, `tests/test_channel.py`
**Produces:**
- `async open_channel(reader, writer, identity, peer_x_pub) -> Channel` (initiator).
- `async accept_channel(reader, writer, identity, lookup: Callable[[bytes], contact|None]) -> Channel` (responder). Noise KK needs the responder to know the initiator's static key, so the initiator first sends a cleartext `hello{fpr}`. The responder looks up that contact and runs KK with the pinned key. An unknown fpr gets `AUTH_FAILURE`.
- `Channel.send(type, body)` and `Channel.recv() -> (type, body)`, with envelope `{msg_id, ts, type, body, anchor}`.
- `Channel.peer_fpr`
- `ReplayGuard(conn).check(msg_id, ts)`
- [ ] Tests:
  - round-trip between two pinned identities;
  - an unpinned initiator is rejected;
  - a tampered ciphertext frame raises;
  - `ReplayGuard` rejects a duplicate msg_id and a skew of more than 300 s.

### Task 6: Groups + engine (policy, leases, rotation)
**Files:** `groups.py`, `engine.py`, `tests/test_groups.py`, `tests/test_engine.py`
**groups.py produces:**
- `make_genesis(...)` and `make_next(prev_doc, changes, signer) -> doc` (custodian changes collect sigs in `sigs: [{fpr, sig}]`).
- `validate_extension(head_doc|None, new_doc, sender_fpr, my_fpr) -> None | raises GroupError(code)`, with codes `NOT_EXTENSION`, `FORK`, `BAD_SIG`, `NOT_CUSTODIAN`, `NEED_MAJORITY`, `GENESIS_NOT_FROM_SIGNER`, `NOT_LISTED`.
**groups.py tests:**
- a member self-promotion is rejected;
- a removed custodian's branch gives `FORK`;
- a custodian change with 1 of 3 sigs gives `NEED_MAJORITY`, and 2 of 3 is OK;
- a genesis not pushed by its signer is rejected.

**engine.py produces:** an `Engine(conn, vault, audit, identity)` with:
- `decide(request) -> "auto"|"manual"|"deny"`. Rules:
  - not a member and `allow_non_member_requests=false` → deny;
  - member, auto policy, `minutes ≤ max` and criticality ≠ Critical → auto;
  - otherwise manual.
- `create_request_out(...)`, `receive_request(req, sender_fpr)`, `approve(request_id, minutes)`, `deny(request_id, comment)`.
- `grant_lease(...) -> lease msg`, `receive_lease(msg)`, `checkin(lease_id)`, `revoke(lease_id)`, `sweep(now) -> list[receipt msgs]`.
- `raise_rotation(cred_id, reason)` and `rotate(cred_id, new_secret)`.
- `has_active_lease(requester, cred_id)`.
- Every action appends audit and returns the outbound messages; it does no I/O.

**engine.py tests:**
- `test_decide_matrix` covers member/non-member, over-max, Critical and the deny policy;
- `test_request_while_soft_locked` auto-approves a group secret with the personal tier locked;
- `test_expired_lease_swept_on_boot` checks the row is deleted and a receipt is emitted;
- `test_duplicate_request_extends` checks one lease row with a later expiry;
- `test_checkin_raises_rotation_for_high`;
- a pending request older than 24 h is marked expired.

### Task 7: Peer service, outbox, custodian sync, discovery
**Files:** `peer.py`, `discovery.py`, `tests/test_peer.py`
**Produces:**
- `PeerService(node).start(host, port)`
- `.deliver(peer_fpr, type, body)`: tries to connect, otherwise writes to `outbox`.
- `.flush_outbox()`, run every 10 s and on any inbound session.
- Pairing sessions: `.begin_pair(addr) -> session_id`. The UI polls the session state through `.pair_sessions`, and `.confirm_pair(id, ok)` resolves it.
- Message types: `request, approval, denial, lease, revoke, receipt, group_doc, group_secret, sync_events, log_query`.
- Custodian sync pushes group events and secrets to co-custodians.
- `Beacon(node).start()`

**Tests:**
- two in-process nodes pair, with both confirming programmatically;
- request → auto lease arrives;
- `test_outbox_redelivers`: the target is stopped, the request is queued, and after the target starts again and the outbox flushes, the request is received;
- body fpr spoofing is rejected.

### Task 8: Seed + Node + API
**Files:** `seed.py`, `node.py`, `api.py`, `tests/test_api.py`
**Seed:** the team and credentials from spec §9 plus the PASM fields. Each node builds only its own state, from `TEAM` and `from_seed`. Secrets come from a per-credential HKDF and are formatted as a strong password. History timestamps are relative to `now`.
**API** (all under `/api`; every route except `/api/status` and `/api/unlock` needs a session cookie, and mutations need an `X-CSRF` header):
- `status`, `unlock`, `lock`, `lock-full`, `dashboard`
- `credentials` CRUD; `credentials/{id}/reveal`; `credentials/{id}/access`
- `catalog` (all requestable credentials from groups and contacts)
- `requests` (GET mine, POST new); `approvals` (GET); `approvals/{id}/approve|deny`
- `leases/in` (GET); `leases/in/{id}/reveal`; `leases/in/{id}/checkin`; `leases/out` (GET); `leases/out/{id}/revoke`
- `groups` (GET); `groups/{id}`; `rotations` (GET); `rotations/{id}/done|dismiss`
- `peers` (GET); `peers/nearby`; `pair` (POST addr); `pair/{sid}` (GET); `pair/{sid}/confirm`
- `audit` (GET with filters); `audit/verify`; `alerts`

**Tests:**
- locked → 401;
- missing CSRF → 403;
- a non-local Host header → 400;
- seeded priya: the dashboard counts match the seed (1 pending approval, 1 rotation due);
- every seeded node's audit verifies.
